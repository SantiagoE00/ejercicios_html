HTML es el lenguaje que se usa para crear la estructura de las páginas web. Con él se definen títulos, párrafos, listas, tablas e imágenes.

Lenguajes de programación
Lenguaje Uso principal
HTML Estructura de páginas web
CSS Estilos y diseño
JavaScript Interactividad

Pasos para crear una página web

  1. Abrir el editor de código
  2. Escribir la estructura HTML
  3. Guardar el archivo con extensión .html

Pasos para ver la página

  1. Abrir el navegador
  2. Cargar el archivo guardado
  3. Revisar el resultado en pantalla
